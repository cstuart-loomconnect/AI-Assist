Placement: six Lightning Component tabs (AI_Home, AI_Agents, AI_Agent_Wizard, AI_Library, AI_Activity, AI_Settings) in the AI Assist
app's nav bar, each showing aiTabPage. The tab's API name is the AINavTab__mdt Developer Name it loads. Component
tabs have no Salesforce page title bar (App Page tabs always draw one), so the console starts right under the nav bar.
The object tabs are no longer in the app's nav bar (they still exist for record pages).

[x] Component / Related List rows -> stacked in the page, three columns, sized by SectionWidth__c (new field)

---------- Design differences ----------
- Text is 1px larger throughout than the design (14px body), at the user's request.
- Modals use LightningModal sizes (medium / small), so their widths are close to, not exactly, the design's 720 / 800 / 920px.
- Tables are SLDS markup rather than lightning-datatable - the design's cells (badges, two-line cells, warnings, selected rows) can't be drawn in a datatable.
- Placeholder copy where the design showed invented examples: the guardrail preview message, workflow action preview input values.
- Added where the design had no control: template Save / Delete, rule Save / Delete, the Workflow Action modal, the PII Add object modal.
