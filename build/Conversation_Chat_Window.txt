---------- Design differences ----------
- Fonts: the design's Instrument Sans / IBM Plex Mono aren't loaded (Lightning's CSP blocks Google Fonts) - Salesforce Sans and the SLDS monospace stack are used.
- Debug mode keeps the full composer (slash commands still work) and swaps the disclaimer for "Debug mode is on for your user only."
- Usage meter says "today" as in the design, but counts the same window the limits enforce (LAST_N_DAYS:1 - yesterday and today).

---------- Access (SOQL at API 67.0 enforces object and field access) ----------
- Every field the chat reads is either granted in AIAssistUser / AIAssistAdminUser / AIAssistSuperUser, or read WITH SYSTEM_MODE
  where users shouldn't hold the access themselves (own AIUserSettings__c row, own User.AIAssistUserType__c, AIPIIRegistry__c badge,
  AIPIIMapping__c, AIModelConfiguration__c names in the debug trace, AI Platform Log reference, Execution Step Data Source names).
- AIChatControllerTest.testScenario17 runs the chat as a Standard User with only AIAssistUser - keep it passing when adding fields.
- Scenario walkthrough for testing every state: build/Chat_Window_Scenarios.txt
